Location → channels → codeplug

Build a codeplug around where you actually operate.

Pick a location, add standard analog channels, pull in nearby Brandmeister DMR repeaters and analog repeaters, then export a file for the official RadioFoundry codeplug editor. Nothing you build leaves this browser.

  • Brandmeister repeaters with their static talkgroups, distances and default contact
  • IARU calling, APRS, PMR446, FRS/GMRS and marine VHF channel packs
  • Analog repeaters with CTCSS/DCS tones from the HearHam open database

2

Standard analog channels

Channel packs add known frequencies to the codeplug. Your country picks the IARU region and the APRS default; you can override the region.

3

Nearby DMR repeaters

Brandmeister's public Halligan API, filtered by distance. The first static talkgroup the API returns becomes the channel's default contact; all of them go into an RX group list, each carrying the timeslot override Brandmeister publishes for that talkgroup on that repeater.

50 km

Default contact

The national Spanish DMR simplex plan (URE / Radio Club Fene) on the IARU Region 1 band plan: 145.375 and 433.450 calling, QSO channels, SOTA, CC1 slot 1. Channel names follow the plan so a contact can agree a QSY by name; the contact in use is appended, as in SOTA-U TG99

4

Nearby analog repeaters

FM repeaters on both bands from URE's national list for Spain and from HearHam's open database elsewhere, with the repeater's shift and any CTCSS/DCS tone. Tone coverage varies; entries without one are marked no tone. Verify a repeater before you transmit.
